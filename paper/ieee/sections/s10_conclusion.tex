\section{Conclusions}\label{sec:conclusion}
On a national panel of Indian mandi series, evaluated without leakage and against honest baselines:
\begin{itemize}
  \item learned models improve on persistence by 3--8\% in MAE;
  \item they improve on a per-series smoother only beyond three days;
  \item cross-market features contribute 17--29\% of the 7-day gain over persistence, and most of that survives a one-day lag;
  \item a global LightGBM is more accurate than the MLlib models, so their gains are not a ceiling.
\end{itemize}
The training loss must match the scoring rule when many target changes are exactly zero.
An incomplete public mirror can manufacture an apparent loss of calibration that disappears on identical rows of the official record, while a smaller accuracy shift remains.
Frozen models keep a significant, if smaller, advantage on later official reports that were absent from the development data. One refit on two further years gave no measurable gain on a final period not used for any retraining choice.
Future work, in order of expected value:
\begin{enumerate}
  \item rolling or scheduled retraining evaluated with rolling origins;
  \item adaptive conformal intervals;
  \item arrivals and weather covariates;
  \item a field study of the decision cards.
\end{enumerate}

\paragraph{Data and code availability.}
All code, configuration, tests, experiment manifests and result files are in the project repository. The repository is public at \url{https://github.com/kaushalrog/AG-DATA}, and the release commit will be tagged at acceptance. A static demonstration of the farmer application, serving a bundled snapshot of real reports, is at \url{https://kaushalrog.github.io/AG-DATA/}. The experiment manifests of the main run record an uncommitted working tree (\texttt{git\_dirty}) and a parent commit that predates the forecasting code; the forecasting code was committed afterwards, so the exact code state of that run cannot be proven from the manifest alone. The data sources are:
\begin{itemize}
  \item the public archive (Kaggle dataset above);
  \item the official data.gov.in resource \texttt{35985678-0d79-46b4-9ed6-6f13308a1d24}, which requires a free key.
\end{itemize}
Every number in the tables is read from result files under \texttt{results/}. These files are written by the Spark jobs and by the scripts in \texttt{py/agri/analysis}. The mapping from each number to its file is in \texttt{docs/VERIFIED\_METRICS.md}.
