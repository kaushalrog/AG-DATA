# AG-DATA Mandi Prices

The AG-DATA farmer web app with its read-only API. It covers official AGMARKNET daily reports for 36 commodities, with 1–14 day forecasts that carry measured-accuracy prediction intervals, in English, Tamil, Telugu, Malayalam, Hindi and Kannada.

* **Data.** AGMARKNET via data.gov.in (GODL-India licence), as of the `data_as_of` date the app shows. The data is refreshed when the project's pipeline republishes; it is not a live feed.
* **Forecasts.** These are a market outlook, not financial advice.
* **Source code.** https://github.com/kaushalrog/AG-DATA
